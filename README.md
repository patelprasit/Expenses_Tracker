# 💰 Expenses Tracker

A simple **Expense Tracker application built using C++** that helps users manage and track their daily expenses. This project demonstrates the practical use of Object-Oriented Programming (OOP) concepts in C++.

## 📌 About the Project

The Expenses Tracker is a C++ college project designed to make expense management simple and organized. It allows users to record and manage their expenses through a structured program.

The project focuses on applying fundamental C++ programming concepts and OOP principles to solve a real-world problem.

## ✨ Features

- Add and manage expense records.
- Organize expense-related information.
- Track expenses in a structured way.
- Simple and user-friendly interface.
- Demonstrates object-oriented programming in C++.

*Note: The exact features depend on the implementation in the source code.*

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming (OOP)
- **Compiler:** GCC, MinGW, or another compatible C++ compiler
- **Editor:** Visual Studio Code or any C++ IDE

## 🧠 OOP Concepts Used

This project can demonstrate the following OOP concepts, depending on their implementation in the source code:

- **Classes and Objects:** Used to organize expense-related data and functionality.
- **Encapsulation:** Combines data and related functions within classes.
- **Abstraction:** Simplifies how users interact with the program.
- **Functions:** Divide the program into manageable tasks.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/patelprasit/Expenses_Tracker.git
```

### 2. Open the Project Folder

```bash
cd Expenses_Tracker
```

### 3. Compile the C++ Program

If the main source file is named `expenses_tracker.cpp`, run:

```bash
g++ expenses_tracker.cpp -o expenses_tracker
```

### 4. Run the Program

**Windows:**

```bash
expenses_tracker.exe
```

**Linux / macOS:**

```bash
./expenses_tracker
```

Make sure a compatible C++ compiler is installed before running the program.
